# Auto-apply criteria for WeMakeDevs2026

We are building fast during a one-day hackathon, so auto-apply generously:

- Apply fixes for lint, formatting, type errors, missing timeouts, missing input
  validation, missing OpenTelemetry spans and missing Kubernetes probes/limits.
- Apply fixes that remove committed secrets.
- Do not auto-apply changes that alter product behaviour, UI copy, search ranking
  or Elasticsearch mappings; leave those as review comments.
